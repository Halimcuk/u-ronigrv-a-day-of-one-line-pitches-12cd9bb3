One sentence, 235 characters, written to persuade a friend who has never coded to let an AI agent build their first app idea on make.fun:

> You've been telling me about that app idea for ages — just describe it in plain words to an AI agent on make.fun, and tonight you'll be tapping through a real first version of it, free to try and with nothing to lose if it's not right.

The program writes exactly that sentence — and nothing else — to `entry.txt` in the output directory. The sentence is a fixed constant in the program: no randomness, no clock, no network, so every run produces identical output. Before writing, the program checks its own sentence is non-empty and at most 240 characters.

## Run it

```sh
node main.ts
```

With the harness output directory set, the entry lands at `$MAKEFUN_OUTPUT_DIR/entry.txt`.
